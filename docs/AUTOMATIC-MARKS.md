# 自动问题识别

在媒体库 → 待处理与质量开启后台自动识别；也可批选或在详情选择自动识别。

安装：`python -m pip install -r requirements-vision.txt`，并准备 FFmpeg/ffprobe。本机采用随依赖安装的本地 OCR 模型，不上传媒体。后台每分钟最多领取一个稳定文件，单线程执行；新文件、重扫变化后的文件及尚未完成识别的文件逐步处理。失败一天后重试，最多三次。暂停开关停止领取，取消队列会停止当前检查并暂停自动领取。

抽取8个时间点识别相近位置持续出现的文字；普通底部字幕被排除。三段抽样检测至少2秒黑屏及至少5秒近静止画面。结果均为疑似，提供规则评分、时间点和证据截图，支持逐项确认、忽略及恢复。评分未经统计校准，台标/片头可能误报，图形Logo/移动水印及未采到区间可能漏报。

人工标记与自动结果独立，忽略会保留审阅记录；重扫发现文件变化后旧结论失效。OCR失败不会产生无水印结论，证据缓存不随主库备份打包。外部最高画质发现和画面语义质量评分尚未实现。

验证：59项后端测试；合成视频8个采样点识别固定文字水印，排除变化字幕，支持忽略并保持原文件哈希不变。Docker新增依赖配置未作真机验证。
