# alpha.5 性能基线与止损

环境：Windows 10内核10.0.26300、Python3.10.6，本机loopback、合成索引，无真实来源请求/OCR/视频字节。2026-11-04。进程峰值由Windows进程计数读取，HTTP请求读取完整响应体，不把接口时间当浏览器绘制时间。

|文件数|旧响应字节|引用传输字节|旧冷请求秒|新冷请求秒|旧峰值字节|新峰值字节|
|---|---:|---:|---:|---:|---:|---:|
|10000|53599870|20213226|2.6074|2.4862|378445824|276013056|
|50000|269239870|101773226|12.6733|12.3190|1749012480|1238364160|

新传输约减少62%响应体及29%五万库峰值。查询和关系推断仍为全量，首次请求改善有限。空闲版本检查204字节，实测约0.002–0.012秒；旧网页每七秒可能重取整个片库。隐藏页面停止轮询，刷新请求不再重叠，未变关系不重复写库。

独立内置浏览器合成页面：一万文件首批48卡片双帧标记3579ms，五万17005ms。标记为首次render后连续两次requestAnimationFrame结束的performance.now，包含加载和客户端过滤/分组，非浏览器FCP统计，也不是所有图片已加载。样本有3个条目合并为一个目录集合，故结果卡片数9998/49998。实际内容、硬盘及机器负载会改变结果。

重现：

```powershell
python scripts/benchmark_library.py --counts 10000 50000 --output D:/Velvet-Test/performance.json
python scripts/preview_alpha5.py --count 10000 --port 18766
python scripts/preview_alpha5.py --count 50000 --port 18767
```

UI脚本只建立临时合成资料，不使用默认个人数据目录，不访问来源网站。大样本不生成实际视频文件。浏览器读取body的data-library-ready-ms可检查双帧标记；隐藏标签可能受浏览器节流影响。

结论：A5本版的基线与冗余止损已有证据，但五万级首屏17秒和约1.24GB峰值仍重。服务端分页/过滤/聚合和增量详情应作为下一阶段P0专项，不能将本次发布称为完成大库优化或五万库体验合格。
