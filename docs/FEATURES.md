# 功能清单 · 0.1.0-alpha.3

更新：2026-11-02。以当前源码为依据；“已实现”指功能路径存在，不等于全部媒体、站点和平台已验收。剩余工作见 [需求表](REQUIREMENTS.md)，交付顺序见 [路线图](ROADMAP.md)。

## 导入、扫描与媒体库

- 系统目录选择器、备用路径输入、服务端目录浏览；递归建立 SQLite 索引。
- 同名 NFO 读取；FFprobe 提取时长、尺寸和编码，FFmpeg 六帧截图。
- 媒体库命名、单库文件列表、状态和标题/编号搜索、分页、单库扫描。
- 每库自动化开关、仅扫描/扫描并刮削、排除规则、最小大小、文件稳定等待时间。
- 定期扫描、取消信号、缺失标记及离线目录保护；发现基于扫描，尚非原生文件监听。
- 资料与缓存写入应用数据目录；原视频不移动、不改名、不删除。

实现：`app.py`、`media_libraries.py`。

## 自动刮削与来源

- 内置引擎独立运行，无需启动 Amane；外部 Amane API 模式可选。
- 10 个内置适配器：JavBus、Jav321、FC2、FC2Club、FC2PPVDB、FreeJavBT、AirAV、XCity、JavDB、JavLibrary。
- 24 项来源目录；其余 14 项标记经外部引擎执行，不能理解为全部已原生移植。
- 编号识别、自动去重提交、在途限额、任务状态/筛选、手动/批量刮削、失败状态、取消与队列恢复逻辑。
- 来源开关、默认顺序、按编号类型路由、逐字段择优及缺值补全。
- 内置 HTTP 代理；各站 HTTPS 地址、超时、有限重试、Cookie；凭据不回传页面。
- 成功来源快照七天缓存复用；手动重新刮削强制获取；修改站点配置使该站缓存失效。
- 验证页、登录、限流、网络错误识别；人工验证不会被自动绕过。
- 文字与封面/海报同步、字段来源对比、手动编辑和字段锁。
- 可选扫描补充 HTTPS JSON 接口；外部模式支持本机 Token 读取及指定连接。

实现：`builtin_scraper.py`、`scrapers/`、`source_catalog.py`、`app.py`。站点可用性和匹配准确率仍依赖网络、账号及命名，恢复一致性需长期验收。详见 [独立刮削](INDEPENDENT-SCRAPING.md)。

## 网络诊断

- 来源连通性、耗时、失败原因、单源重测、有界并发。
- 内置检测与采集共用代理和站点配置；外部模式调用 Amane 实际检测接口。
- 检测不修改影片资料；连通成功不保证具体编号可采集。

实现：`network_checks.py`、`scrapers/compat.py`、`scrapers/block.py`。

## 分类、标签与筛选

- 文本搜索；时长、分辨率、VR、内容标记、演员、厂商、资料状态和缺失筛选。
- 多标签 AND/OR、排除标签；收藏、尚未观看、继续观看、随机挑选和排序。
- 技术属性/路径/关键词自动标签、来源题材、手工标签及分类原因；题材别名保留来源原值。
- 分类页：题材、厂商、系列、导演、我的标签、媒体属性；搜索、收藏和关联影片。
- 分类数量按影片去重，同时显示本地文件数；系列和导演依赖已有元数据。
- 设置中以 JSON 编辑分类规则；尚无可视化合并、冲突治理、动态筛选保存。

实现：`app.py`、`people_catalog.py`、`index.html`、`browse.js`。主片库仍包含全量返回，大库性能未建立基线。

## 卡片、详情与图片

- 稳定横版/海报布局、缩略图回退、两行标题、演员入口、收藏/观看状态。
- 封面下方的分辨率徽标和带时钟图标的时长；圆环批选，无悬停“查看”；可关闭的延迟本地截图轮播。
- 4K 及以上尺寸标识、VR、内容类型徽标、版本/分段提示。
- 阅读优先详情：海报、资料、简介、演员；播放与字段编辑按需展开。
- 剧照/本地截图分组、放大、上一张/下一张及方向键操作。
- 持久化剧照任务、引擎记录、去重与失败单项重试；图片失败不重新刮削文字。
- 每文件最多 12 张剧照任务；常规同步每批最多 24 张，约 45 秒后停止领取下一项，单张请求仍等自身超时。
- 主片库备份包含剧照任务，不含图片文件和独立来源缓存。

实现：`artwork_store.py`、`film_detail.js`、`browse.js/css`。尚无候选选图、黑帧规避、采样设置和真实短视频预览。

## 演员库

- 姓名搜索、收藏筛选、作品数/评分排序、独立评分收藏、参演影片聚合。
- 人物头像、已获取的别名/简介/基础资料；按需获取本页人物并缓存。
- Amane 姓名精确匹配；同名歧义不自动挑选。GFriends 索引可补头像，不保证补全人物资料。
- 占位图、失败缓存、本页重抓；失败响应不覆盖有效图。
- 只聚合本片库人物；尚无人工别名合并、稳定人物 ID 治理或完整外部人物库导入。

实现：`people_catalog.py`、`browse.js`。人物资料与影片采集是不同通道，部分资料依赖外部服务。

## 影片、版本、分段与重复

- 影片 → 版本 → 分段 → 文件关系、默认版本、版本/分段选择、手动关系编辑、拆分和上次变更撤销。
- 自动推断依赖编号、目录和命名；可人工纠正，不改源文件。
- 同大小候选完整 SHA-256 校验；同编号仅为版本候选，不等于内容重复。
- 重复组对比、优先保留与默认版本联动、撤销，不删除副本。
- 尚无不同编码同画面的感知指纹、跨组完整冲突治理或空间清理流程。

实现：`library_core.py`、`app.py`、`index.html`。

## 播放与观看

- HTTP Range 直放、进度记录、续播、分段接续流程。
- 本机系统播放器入口；NAS 模式不调用服务端桌面播放器。
- 受浏览器编码能力限制；无转码、音轨/字幕选择、外部播放器进度回传或独立观看历史页。
- 连播已做模型/模拟验证，真实媒体、异常中断和不同浏览器仍需完整验收。

## 管理交互与运行

- 媒体库、刮削中心、设置三个入口及固定职责；上下文刮削进入同一任务体系。
- 固定管理标题/操作区、面包屑、父级返回、分区高亮；备份与重复检查为页面。
- URL 保存管理页面及相关筛选；刷新/前进后退恢复；返回片库恢复浏览上下文。
- 切页取消旧请求及轮询，未保存修改提示；浅/深色、窄屏样式、基础键盘操作。
- 回环监听、实验 NAS 认证/只读挂载配置、健康信息。

实现：`manager_routes.js`、`management.js/css`。多标签页、完整无障碍和真实手机待系统验收。

## 数据、部署与交付

- 主库、偏好、规则和配置备份，恢复校验及回滚点。
- `VELVET_DATA` 数据目录、Windows 启动脚本、跨平台 Python 启动、实验 Docker Compose。
- GPL-3.0；采集来源/修改见 `NOTICE`；源码不含私人媒体、数据库、缓存或凭据。
- `VERSION` 统一版本；发布脚本检查公开文件、文档链接和 JS 语法，从 Git 生成源码包及 SHA-256。

## 文件质量与待处理（新增）

只读快速/抽样/完整解码检查、持久队列及取消/重启重查；人工水印/损坏/更新标记，备注、接受、忽略与撤销。个人画质目标、本地更高分辨率候选、卡片徽标和批量筛选；资料失败/缺字段/缺封面集中审阅。实现：`file_review.py/js`。范围与限制见 [文件质量](FILE-QUALITY.md)，不代表全部 P0 已完成。

## AI 的准确边界

AI 参与需求、开发与文档协作。产品内尚无 LLM、视觉识别、语义标签、向量检索或自然语言片单；关键词分类不是视觉 AI。未来模型应可选、明确数据范围，建议由用户审阅。


## alpha.6开发候选：文件组跳过

停止整理任务后，可明确审阅并跳过尚未提交的视频及其归属资源，刷新/重启保留决定，其余文件仍须点击继续。完成和跳过分别计数，历史显示“已结束 · 含跳过”；再次整理需新计划。已暂存移动/提交/绑定、归档及撤销任务不提供跳过。原媒体与已提交目标保留，复制残片另行核对清理。此为尚未发布的开发候选，见[操作](ALPHA6-OPERATIONS.md)与[ADR0011](adr/0011-explicit-precommit-group-skip.md)，不代表alpha.6全量验收完成。
