# 功能结构及体验审计 · alpha.4

日期：2026-11-04。以下来自当前代码审查及既有验证，不宣称覆盖所有真实使用问题。已实现入口不等于完整验收；没有全新全流程浏览器验收。

## 当前结构

|层级|职责|建议|
|---|---|---|
|片库|搜索、筛选、分页、影片/目录合集浏览|保留主入口，减少顶部长期按钮|
|影片详情|资料、图片、版本/分段、播放、编辑、文件质量|拆清影片级和当前文件级；低频管理收进更多操作|
|视频集|目录聚合、成员缩略图及自然排序|只做展示分组，需独立页面与稳定地址|
|演员与分类|人物偏好、题材/厂商/系列等关联浏览|与影片保持相同返回和筛选记忆|
|媒体库|目录、自动化、文件列表、排除、重复检查|目录操作集中于此，片库只留上下文快捷入口|
|待处理|资料缺失、质量问题、检查与人工审阅|建议独立为管理入口，区别资料与文件问题|
|刮削中心|来源、站点凭据、执行网络、任务|连接设置与日常执行分层，统一后台任务|
|设置|运行、分类规则、备份恢复|隐私/预览/布局偏好应可从此管理|

## 问题清单与优先级

|ID|优先级|不合理之处|改进与验收|
|---|---|---|---|
|U01|P0|后台扫描、刮削、图片、OCR分别维护状态|统一任务摘要、取消、错误、重启对账；中断重启有可复现测试|
|U02|P0|启动依赖终端/后台进程，曾出现退出后服务停止|单实例启停、健康检查、失败日志与重启入口|
|U03|P0|大部分资料仍全量返回并定时刷新|服务端分页/筛选、增量更新；先记录1万/5万文件基线|
|U04|P0|扫描占用时自动识别等待，用户不清楚原因|明确等待原因、队列长度、当前阶段和暂停范围|
|U05|P0|合集只按名称标记猜测，未标记目录可能漏组|支持人工指定合集根、取消归组、影响预览，不自动改影片关系|
|U06|P0|目录排除缺影响数量预览，容易排除过大范围|显示目录与子目录影响，提供撤销；排除与恢复立即一致|
|U07|P0|排除可能仍留在已有检查队列和部分聚合统计|扫描/任务/演员/分类/计数统一排除策略，覆盖恢复与多版本|
|U08|P0|主库备份不包含独立来源库及图片证据|全量备份范围明确、恢复演练、升级前快照与可回滚流程|
|U09|P0|缺浏览器端到端回归，语法通过不能保证交互|合成片库验证筛选、分页、返回、弹窗、隐私、合集和排除|
|U10|P1|顶部开关/管理按钮堆积|保留搜索、导入、隐私；预览、布局、页大小归显示菜单|
|U11|P1|待处理藏在媒体库且同时有顶部入口|统一一个独立管理入口，上下文操作只负责跳转|
|U12|P1|影片/版本/分段/目录合集概念容易混淆|明确徽标、层级和操作范围；不同类型不共享含混名称|
|U13|P1|合集是工具弹窗，无独立URL，关闭详情返回不完全一致|独立合集页、地址、滚动/焦点恢复和面包屑|
|U14|P1|合集归组在筛选之后，数量仅为命中成员|同时显示命中/总数，允许查看全集；禁止暗示已列出所有文件|
|U15|P1|合集未有独立封面和资料，封面拼图依赖成员缓存|候选选图、重采样、空状态和单集封面选择|
|U16|P1|工具弹窗共用样式与事件，可能互相影响|按页面职责拆分；切换弹窗、返回和关闭系统回归|
|U17|P1|分页改进仅覆盖视频，演员等仍旧交互|统一页码、大小、跳转、禁用态和历史行为|
|U18|P1|翻页可能保留其他页选择，批量范围不直观|显示跨页选择范围、一键清空、本页/所有结果分开|
|U19|P1|过滤条件冲突时只有空结果，缺解释|条件摘要、命中数、清除建议和版本命中说明|
|U20|P1|自动水印阈值固定，评分未经校准|阈值配置、误报反馈样本和评估集；保持疑似标记|
|U21|P1|自动确认按问题类型而非每条文字证据区分|稳定发现ID，逐项审阅，重跑可追踪变化|
|U22|P1|OCR抽样漏图形/移动水印，黑屏静止可能是正常镜头|明确检测范围，支持更多采样与人工复核，不能据此确认损坏|
|U23|P1|“更高分辨率”不等于更好版本|尺寸、编码、码率、来源、完整性分开；禁止自动删除替换|
|U24|P1|画质目标全局、接受状态也是文件级|按库/影片目标与问题级决策，修改目标提示重评|
|U25|P1|未匹配编号有父目录回退，但置信度和候选不透明|预览文件/父目录识别来源，人工改编号及锁定|
|U26|P1|JSON分类规则难编辑|可视化规则、别名合并、影响预览、冲突和撤销|
|U27|P1|人物身份按姓名，别名和同名治理不足|稳定ID、人工合并、迁移偏好、可撤销|
|U28|P1|隐私只遮画面，标题路径文字仍显示|可选隐藏文字；多标签页同步、刷新无闪图、所有弹窗审计|
|U29|P1|详情信息密集，质量审阅挤占日常选片空间|概览优先，问题摘要展开；文件操作独立区|
|U30|P1|查看详情期间后台更新可能改变状态但表单未保存|脏表单保护、更新提示、冲突处理和范围明确|
|U31|P1|字幕/音轨选择和编码兼容提示不足|枚举轨道、外挂字幕、无法直放时明确回退|
|U32|P1|系统播放器不回传进度，易误以为可续播|明确外部播放限制，后续提供可选协议接入|
|U33|P1|目前无动态片单/多个收藏集|保存筛选、手工片单、排序与首页分区|
|U34|P1|目录路径在NAS和本机语义不同|服务端路径提示、映射说明、权限错误与离线状态|
|U35|P1|排除规则与精确目录排除是两套机制|同页管理、解释区别、统一影响预览|
|U36|P2|缺图库缓存容量与清理策略|显示容量，按可再生/证据分类，清理不破坏主资料|
|U37|P2|新功能依赖不断增加，缺安装诊断|分基础/采集/OCR依赖、检测与升级路径；NAS镜像实机验证|
|U38|P2|键盘、对比度、触摸和阅读器仅局部支持|完整无障碍与真机检查|
|U39|P2|前端通过函数包装叠加扩展，后端入口集中|分离路由、状态、视图、任务和数据层；逐步迁移而非一次重写|
|U40|P2|文档与小步提交容易领先于正式发布包|版本化功能审计、发布包解压测试、已验证环境说明|
