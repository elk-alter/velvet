# Velvet 0.1.0-alpha.13

这版集中改善片库浏览、添加硬盘位置和从待处理恢复工作的流程。

- 管理页从左上角返回上一级，弹窗从右上角关闭，返回时恢复有效的列表上下文。
- 硬盘位置可直接浏览盘符或粘贴路径。登记前检查重复位置及设备身份，可同时启动盘点。
- 组合筛选在一个窗口内完成，确认后统一生效。跨页选择有常驻范围提示。
- 视频在详情内播放。离线、读取失败与格式不支持分别提示，Windows 本地模式可调用系统播放器。发现同名 VTT 或 SRT 时可切换字幕，音轨选项由浏览器支持情况决定。
- 待处理按问题归类，批量重试先核对提交范围；硬盘首页汇集待恢复任务。

Windows 用户可解压源码附件，使用 Python 3.10 或更新版本运行 `python app.py`。已有安装升级时沿用原数据目录，并先完成可恢复的数据库备份。校验文件与源码 ZIP 一同提供。需求和验证记录见 [alpha.13 需求](ALPHA13-REQUIREMENTS.md) 和 [交付台账](DELIVERY-STATUS.md)。
