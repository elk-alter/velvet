# 界面规范

共享样式在 `velvet.css`。浅色和深色使用同一组语义变量。控件使用 `--control`，主要操作使用 `--accent` 和 `--on-accent`，弱选择使用 `--accent-soft`。首层表面使用 `--panel`，需要分组的区块使用 `--surface-quiet`。字号、间距、圆角与焦点沿用同层变量。如有单个页面的必需差异，定义在相应的组件样式内。

| 区域 | 复用方式 |
|---|---|
| 浏览页 | 使用 `.top` 或 `.browseHeading` 的标题，搜索与筛选共用 `.filterPanel`，分页沿用 `.pager`，空结果使用 `.empty`。 |
| 主操作 | 每个工作区突出当前的主要动作，`.accent` 用于主要提交。批选动作按选择状态出现，低频选项用原生 `details` 收纳。 |
| 管理页 | 通过 `renderManagerShell` 复用管理页头、导航、正文和底部操作。配置区用 `.settingsSection`，任务状态用 `.taskPill` 保留文字和语义颜色。 |
| 弹窗与详情 | `.dialogChrome` 持有标题与独立关闭按钮，`.dialogBody` 提供滚动，`.dialogFooter` 保留操作。详情概览和剧照优先，`.filmDisclosure` 承载补充表单。 |

全页管理层级使用 `.managerBack`，优先恢复有效的来源参数与位置。弹窗可复用 `workflowHeader`，关闭后恢复触发控件。片库筛选使用统一草稿提交，目录选择保留来源表单，播放故障显示在该分段播放器内。

用合成资料检查 390px 窄屏和桌面、浅色和深色，以及长标题、空列表和失效资源。验证键盘焦点位置、窗口滚动、刷新或返回后的上下文，以及开启隐私时封面、截图和标题等相关区域的表现。
