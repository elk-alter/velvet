# 管理区导航

管理区统一为三个入口，浏览资料与管理配置分别导航。

| 入口 | 页面与职责 |
| --- | --- |
| 媒体库 | 目录与自动化策略、单库文件列表、配置、重复内容检查、待处理与文件质量 |
| 刮削中心 | 任务、来源目录与字段择优、站点凭据、执行引擎及代理、网络检测 |
| 设置 | 常规运行参数、分类别名及关键词规则、备份恢复 |

- 单库文件和配置页有明确的父级返回；影片详情关闭后保留文件列表。
- URL 保存当前管理页面、媒体库、来源、文件筛选和任务筛选；刷新及浏览器前进后退可恢复。
- 返回片库恢复进入管理前的浏览筛选与位置。
- 切页取消旧读取请求和页面轮询；未保存表单离开前提示。
- 刮削模式切换时仅展示相关连接字段。高级 JSON 接口保留在执行设置内。
- 分类规则仍使用 JSON 编辑，后续可增加可视化规则编辑器。

本次只重组管理交互，媒体原文件不改名、不移动。

文件检查/标记与目标设置见 [文件质量](FILE-QUALITY.md)。
