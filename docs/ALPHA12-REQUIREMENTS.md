# alpha.12 常用操作顺畅

以已交付的 alpha.11 为基线。保持片库当前筛选、页码和位置，使各项操作可以在出现问题的地方完成。

| ID | 优先级 | 使用场景与验收 |
|---|---|---|
| A12-01 | P0 | 片库显示当前生效的筛选条件和命中范围。可单独撤销条件，标签沿用多选与 AND/OR。恢复命名预设时核对标题和分页。选择模式明确区分本页已选、跨页已选与合集的匹配作品。 |
| A12-02 | P0 | 在当前结果页或合集内打开详情后，可按当前列表顺序看相邻作品。版本与分段仍属于当前作品。关闭回到起点，打开过程中后到的请求不能替换新详情，未保存编辑继续受保护。 |
| A12-03 | P0 | 待处理列表就地查看最近刮削失败原因、打开编号编辑或用已有资料补封面。操作后保留筛选、页码和有效选择。补图失败保留原图和资料，已锁定资料仍按原规则处理。 |
| A12-04 | P0 | 从硬盘查询到计划和确认可看清筛选、已选数量和文件范围。可从计划审阅返回原固定列表及选择；查询过期时提示按原条件重新获取。离线、目标冲突和校验阶段提供对应下一步。 |
| A12-05 | P0 | 五万条 Windows 合成记录，首次建索引首屏中位数 ≤3.5 秒；等待达 1 秒前出现真实阶段进度。保留索引重启首屏中位数 ≤1 秒，详情可操作 p95 ≤200 毫秒，翻页 p95 ≤300 毫秒。 |
| A12-06 | P0 | 用合成资料验证桌面和 390px 的筛选、详情、补资料和硬盘流程。全量回归及 alpha.11 升级、回滚通过，发行和上线另按交付台账记录。 |

详情连续浏览的顺序来自打开时的结果页。合集在同级列表保持独立入口，页内穿过时跳过合集卡片；进入合集后可在它的结果页内连续查看。浏览器仍按原路径提供独立翻页。画面识别、NAS、新的物理整理策略和播放内核扩展保留在后续路线图。
