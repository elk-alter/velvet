# Velvet 0.1.0-alpha.10

本次预发布集中改善标签、演员和片库浏览。

- **管理 → 分类规则**支持逐行编辑标签别名和关键词规则。保存前可看受影响文件数及变化样例，也可预览并撤销最近一次规则变更。
- **管理 → 演员身份**支持合并别名和按文件拆分同名演员。合并或拆分前可选定目标身份的评分与收藏，并查看受影响资料。
- **片库**支持命名并复用筛选。演员与分类支持分页和跳页，筛选无结果时显示当前约束。
- **视频集**可以指定当前合集成员作为封面，也可恢复自动拼图。
- **隐私模式**可同时遮盖常见的标题和路径。偏好会同步到同一浏览器的其他标签页。

规则、演员身份和合集封面保存在本地数据目录。筛选预设和隐私选项保存在当前浏览器。演员和标签治理保留原始资料以及最近一次操作的撤销记录。

附件为源码 ZIP 和对应 SHA-256 校验值。Windows 本机升级步骤见 [部署与升级](DEPLOYMENT.md)。后续的 NAS、换盘符及 exFAT 实盘覆盖见 [路线图](ROADMAP.md)。
