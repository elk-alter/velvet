# Velvet 0.1.0-alpha.7

这是一个源码预发布版。安装依赖及启动方法见 [README](../README.md)。

- 片库按需加载缩略图和详情。索引构建期间显示进度，失败后可以重试。筛选支持标签多选、跨页选择和按条件清空。
- 刮削任务按状态和失败原因查询完整历史，可重试选中的失败任务或单独补图。详情显示识别依据，手动更正后可锁定编号。
- 质量检查可逐条确认或忽略自动发现，文件变化后旧结果失效。版本对比列出分辨率、编码、估算码率和检查结果。
- 整理任务在核对卷、目录和文件身份后可重连，已绑定位置及未完成检查点分别处理。原批准清单保留，可审阅撤销。
- 卡片支持国产和素人手动标记。详情、合集、演员作品及管理页面改进了返回和草稿保护。

## 验证范围

主要验收使用 Windows NTFS 上的独立合成数据。5 万条合成片库空索引首屏中位数为 3.477 秒，保留索引后重启中位数为 979 毫秒。扫描、OCR、合成图片来源及整理复制并发测量见 [交接记录](HANDOFF.md)。刮削批量重试及单独补图使用本地合成响应验证，在线来源受站点和网络状态影响。外接盘拔插、实际换盘符、exFAT 和多分区实机验证见 [需求范围](ALPHA7-REQUIREMENTS.md)。

## 升级和回滚

从 alpha.6 升级前等待任务停止，保留旧程序和完整离线数据快照。将新版解压至新目录，对数据副本进行迁移。先核对健康版本、片库数量、人工锁定、任务和播放，再恢复自动化设置。若需要回滚，请使用旧程序与升级前的数据快照。详细步骤见 [部署与升级](DEPLOYMENT.md)。
