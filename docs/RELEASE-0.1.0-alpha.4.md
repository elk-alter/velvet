# Velvet 0.1.0-alpha.4

本版汇总自动OCR问题标记、证据确认/忽略、后台检查、隐私遮图、目录名称回退与合集、多层分集缩略图、分页跳转和可恢复目录排除。

修复详情刷新丢失快速排除入口，以及短视频显示0分钟。新增功能结构及40项体验问题审计，后续优先任务/启停/排除一致性与端到端验证，再整理合集页面、导航和审阅治理。

仍为Alpha：OCR会误报漏报；画质尺寸不证明视觉质量；完整恢复、大库、全平台/NAS和真实编码矩阵未完成。源码需要Python3.10+，采集依赖requirements.txt，OCR可选requirements-vision.txt及FFmpeg。升级前停止任务并备份完整data；回滚使用旧程序及升级前快照。

本版运行62项后端测试、Python/JS语法和文档链接检查；源码附件解压后执行同套测试。未进行本版完整浏览器端到端验收。详见docs/UX-AUDIT.md。GPL-3.0，第三方声明见NOTICE。
