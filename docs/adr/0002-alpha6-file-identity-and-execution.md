# ADR 0002：alpha.6文件身份、物理位置与执行边界

日期：2026-11-04。状态：采纳数据层方向，执行器待实现与验证。关联A6-03、08–19、28–29。

## 决定

不将复制结果插成新的作品，也不只覆盖videos.path。新增media_assets：稳定UUID关联原video_id；media_locations：设备身份、物理路径、完整指纹、验证时间、首选位置和所属任务；media_location_events记录绑定与选择。旧video_id继续承担原有封面缓存、人工资料、播放状态和关系引用。

旧库迁移仅复制索引，不读取磁盘，离线条目明确未验证、设备未知；重复迁移保持UUID与位置不变。相同字节不自动合并不同人工作品身份。新位置须经源/目标完整SHA-256、文件指纹及设备身份核对。切换位置必须重新验证；路径被其他视频占用时事务失败，不覆盖其它身份。

media_locations当前是独立数据层原型，尚未挂HTTP或启动迁移。默认路径切换只更新DB，不操作媒体；接入LibraryCore前必须完成自动关系稳定策略、离线候选选择和历史路径搜索，否则不得暴露成品入口。不能以当前单元测试宣称A6-17/18已完成。

## 执行器契约（尚待实现）

批准计划冻结来源/目标设备、完整指纹、规则版本和条目集。执行器持有按设备/文件的操作租约；任务/步骤日志先于文件操作提交。复制经独占暂存→刷写→完整校验→不覆盖提交→位置绑定；不同步骤失败分别对账。source/target外部变化与设备替换必须使批准失效。

同盘改名/移动先记录反向步骤，处理名称互换；跨盘默认保源，归档另行确认，永久删除不实现。备份回滚不等于文件操作回滚，恢复执行日志前必须核实实际位置。与扫描、OCR、刮削、备份恢复的互斥必须由统一租约执行，不能只在页面禁用按钮。

## 授权与测试

本次开发仅在TemporaryDirectory合成媒体中写入/改名/断盘模拟。生产原目录仍只读；产品的写能力只限用户明确批准的计划及其拥有的暂存/归档位置。无需用户批准每次合成测试，但不能将开发目标当成真实硬盘的执行授权。

验证需要设备更换、源变化、内容不一致、绑定幂等、元数据保护、故障状态边界、恢复/撤销及真实NTFS/exFAT证据。当前仅完成数据层测试，不代替执行器、浏览器、性能或设备验收。

## 批准及日志实现补充

organization_drafts保存不可变草稿及内容摘要；organization_jobs以approval_digest唯一去重；organization_steps及events保存每个状态边界；organization_leases以设备资源唯一约束互斥，事务失败回滚部分获取。copying→verified→committing→committed→binding→done分开记录，不能以文件已复制代替已绑定。

recover仅在持有整个数据目录DataGuard的启动阶段调用，不允许活跃执行器运行时清除租约。当前仅组织模块消费租约；扫描/媒体检查/恢复尚未接入，后续集成门槛仍保留。原生文件操作、资源伴随文件、移动批准与执行暂未实现。

## 复制执行实现补充

CopyExecutor采用逐文件重做。copying阶段进程中断/取消保留原暂存文件，重做创建新独占暂存并记录旧路径，不自动推断可删除。verified/committing/committed阶段恢复核对日志记录的文件身份与完整哈希；不能仅因同内容目标存在就认领外部文件。Windows使用MoveFileW的不覆盖行为提交；POSIX使用同目录link的不覆盖行为，不支持该能力的文件系统报错，不降级为覆盖rename。

绑定为注入的数据层回调，返回确切绑定标识后才能done。提交后绑定失败单独重试；应用层仍需接入完整身份、元数据与关系适配，当前单元注入不代替成品验收。取消检查覆盖源哈希和复制块；临时清理、移动和设备实际支持范围继续按A6验收。
