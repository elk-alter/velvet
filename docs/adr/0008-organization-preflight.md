# ADR0008：统一整理预检与同盘原目录整理

日期：2026-11-05。状态：采纳（完整平台/故障验收仍待完成）。关联：A6-07–10、15–16、28。

## 问题与决定

预览曾标出长路径，但直接生成草稿可以接受同一条目；权限、Unicode目标变体和整批资源空间没有共用执行门禁。只在页面禁用按钮、或只在复制单文件时检查剩余空间，无法保护固定批准。引入organization_preflight：预览、草稿、批准、实际执行/提交边界复用名称、路径、权限与容量规则。它不写源文件或探测文件，不申请新权限。

## 检查范围

- 用NFC与casefold保守发现计划内及已有名称变体，包含父目录。移动只允许本次选中的源位置占用目标，不认领未选源、外部变体或硬链接别名。最终提交仍用原不覆盖原语，预检不代替文件归属验证。
- 合法名称验证与safe_component名称生成分开：现有.hidden目录可用；保留设备名、不兼容字符、尾部点/空格等拒绝。.velvet-archive仅受控archive入口例外，原强制排除/副本证明保持。
- 原始输入在resolve前检查链接/重解析点，避免抹去绕行依据。no_links移入预检模块，organization_jobs仍兼容导出。Windows目标与任务暂存名均按UTF-16长度保守限制240；目录组件另按本机文件系统编码长度约束。已批准旧日志不重写，不清残片绕过限制；长路径历史恢复矩阵仍需继续验收。
- Windows以当前令牌打开已有目录/源文件，分别请求创建文件/必要子目录、读取或移动删除权限；不创建探针。其它平台用os.access，未据此宣称POSIX/NAS ACL已经实测。继承权限、挂载和外部进程可在预检后变化，故执行边界重新检查，原日志/失败恢复保持。
- 复制按目标设备汇总所选视频及明确归属资源，新增字节加max(100MiB、最大单文件、5%)预留；共享/不可用资源不计入复制。移动不重复预留整份内容，仅16MiB元数据余量；keep只核验读取，不要求写权限/额外容量。逐项检查只读卷与FAT32 4GiB限制。预留是检查条件，不是磁盘配额或预分配承诺。

## 批准、执行及数据

草稿payload.preflight保存version=1及设备/文件系统、required/reserve，参与摘要；不把会浮动的free写入摘要。旧草稿无此字段也会在批准/执行时按当前规则核对。新字段不新增业务表；完整文件哈希、身份、设备、规则版本与步骤日志继续是权威。新草稿不能用当前检测结果替换调用者已有的source_device/source_identity/fingerprint证明；资产登记前再次比对原盘点设备，避免在完整校验期间采纳替换卷。

同盘move允许目标等于或位于原盘点根内，支持原目录归组和大小写改名；copy仍要求与全部所选源根独立。先全批暂存后提交的既有策略保持。暂存前发现冲突，任务failed且源仍原位；暂存后冲突则保留现场与反向恢复。PreflightError代码写入步骤，服务端提供人类可读提示；不让用户从异常类名猜原因。

目录名称索引和属性/权限结果仅在一次预检复用，避免N×目录扫描或N×源集合构造；不跨批准/执行复用，提交前重新检查。缓存结果不是持续有效的文件系统锁。

## 验证及未完成

合成NTFS单测包括长路径与暂存预算、非BMP长度、合法隐藏目录、大小写/NFC/NFD、父文件/目录变体、保留名、实际junction拒绝、真正NTFS DACL拒绝/恢复、FAT32和空间模拟、批准后权限变化、校验后外部变体、移动前/暂存后冲突、未选源保护、设备时序与旧证明拒绝；另有浏览器复制/调整/原目录move/撤销和C/D实际跨卷回归。

FAT32/只读卷/空间耗尽为确定性模拟，不是真实FAT32或拔盘。exFAT设备仍缺；完整持久状态故障、老日志恢复、全部元数据和平台/性能验收继续，不能以此ADR标记整版P0通过。
