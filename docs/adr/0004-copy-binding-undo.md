# ADR 0004：复制撤销只解除绑定，保留物理文件

日期：2026-11-05。状态：alpha.6开发候选。关联A6-16–19、28，补充[文件身份与执行](0002-alpha6-file-identity-and-execution.md)。

## 决定

复制撤销复用organization_drafts、organization_jobs、organization_inverses、持久控制和资源租约。operation为unbind_copy，不通过普通copy/move批准入口。审阅/批准时原任务须已停止，waiting须明确暂停；维护标记阻止原任务领取。可进入原任务自己的对账隔离，不能绕过其它任务隔离。

草稿冻结本任务目标绑定、资产UUID及数字ID、当前播放位置、目标文件身份和完整哈希。仅解除origin_task仍为原任务的目标位置/资源关联。已提交但未绑定的目标不假装已撤销，列为保留；没有本任务绑定则拒绝空撤销。原任务批准反向任务后不能继续，重复批准返回同一任务。未批准旧草稿可重新审阅生成当前摘要，旧摘要失效。已批准但停止/失败的原子撤销可重新审阅；新草稿含被替代任务ID，旧任务持久标记作废并禁止claim/resume，不能复用旧批准摘要。执行中/排队中的撤销须先暂停或取消。

若目标是默认播放位置，必须核验仍保留的原文件或另一份副本，且该位置不能也在本次解除范围。无可用替代文件时提示连接原盘/有效副本，不把未知离线位置伪装成可播放。目标非默认位置时保持用户后来选择的默认位置。目标被替换、内容变化、归属改变、作品移除或默认位置变化均拒绝旧计划。资料锁、评分、收藏、续播、关系与现存质量决策不重建。

完整哈希读取在数据库写事务之外，执行前再次核对；数据库事务内复检绑定与文件身份/大小/mtime/设备。所有解除、默认位置切换、证据时间更新、事件、步骤完成和任务完成一起提交。提交前故障全部回滚；提交后重启看到done，不重复解除。取消/暂停在校验边界生效，不在事务中间写一半数据。执行不复制、改名或删除任何原文件、目标或伴随资源。

## 边界与替代方案

不把“撤销复制”实现为删除目标，也不对原文件做反向复制。保留目标文件意味着再次扫描目标目录可重新导入它，界面明确说明。它不是文件删除/隔离能力，不代替受控源归档、移动反向计划、复制残片清理或备份/文件日志对账。现有恢复保护继续保守执行。

进度按完成绑定数展示，不能用复制字节冒充发生了数据搬运。既有任务仍需完整设备/故障矩阵与大批次验收；本批不代表A6-16或alpha.6全部通过。

## 验证

隔离合成文件测试包含原始/已入库视频及字幕、资料/质量保留、后来默认位置、同内容外部替换、源变化/重审、普通批准旁路拒绝、租约等待、暂停取消重启、提交前/后故障和实际HTTP确认/分页。最终命令及浏览器证据见[进度](../ALPHA6-PROGRESS.md)。
