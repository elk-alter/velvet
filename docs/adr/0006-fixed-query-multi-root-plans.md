# ADR 0006：固定跨盘查询选择与多来源整理计划

日期：2026-11-05。状态：alpha.6开发候选。关联A6-02、06–08、11、16、20、24–25。

## 选择与规划

物理查询为当前页附query_ordinal。选择绑定缓存查询snapshot中的有序成员，接受显式ordinal列表、all或exclude列表；服务端校验过期、设备/排除/建议签名和范围，不把无效编号忽略。全部匹配后取消少数文件是固定范围差集，不重新运行最新查询。摘要显示文件/字节/来源位置，离线成员不静默跳过。新盘点可保留旧固定范围，生成计划仍读取各自file_snapshot，执行前另核对真实文件。

QueryPlanner复用原目录模板/冲突预检，按固定快照和相对路径读各来源后合成一份organization_plan。前后再次验证查询，期间上下文变化拒绝发布混合计划。来源映射、原快照、具体文件、操作、目标和摘要持久化；查询缓存过期不会把已生成计划扩展成新结果。目标同名冲突由用户修改/取消选择，不自动丢弃或偷偷改成按盘分目录。

query-plan只返回id、摘要、计数等，完整清单从preview/draft分页读取。服务端仍会构建完整计划，未宣称五万项批量规划性能通过。选择请求上限2MB，仅专用选择/规划/prepare路由；其它请求维持原限制。无效/过期上下文409，其它非法选择400。

## 执行与旧日志

一个任务保存source_roots/target_roots和逐项source_root/target_root；逐项路径必须归属已批准根列表，复制目标与全部选中来源保持独立。不能用不同盘符的字符串共同祖先冒充授权根。同盘移动按每项卷身份检查，跨盘仍须复制。资源、字段/UUID/旧video_id、取消恢复和租约复用原流程。

反向移动按每项原根和已证明归属的当前位置生成计划，不对不同盘符调用commonpath。源归档为每项原根选择同盘可恢复位置并保护所有归档根，保持已验证目标副本；原copy之后源设备、文件身份或完整指纹变化时禁止归档。旧单根计划/已批准日志仍回退source_root/target_root字符串，补充旧归档草稿批准及恢复回归。

## 页面语义

DiskFileSelection独立维护物理范围，与片库作品选择、计划条目选择分开。翻页及返回规则页保持范围和字节；全部匹配可逐项取消。筛选/查询更换清空旧范围并解释。浏览器刷新不暗中恢复全部匹配：选择丢失时明确要求重新选择，返回保留原文件筛选/分页参数。生成只读计划不等于执行批准。

## 验收边界

本批合成多根均在同一Windows NTFS卷，支持代码里的多卷根列表不等同实际跨卷/exFAT验收。完整设备、并发、超大规划、预检/故障及返回矩阵仍见[进度](../ALPHA6-PROGRESS.md)。
