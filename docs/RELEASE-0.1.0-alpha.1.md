# Velvet 0.1.0-alpha.1

首次公开测试版：一个 AI 辅助开发、以本地收藏为中心的视频库实验。

包含目录索引、元数据任务、封面/截图、影片版本与分段关系、组合筛选、人物偏好、浏览器直放和非破坏性重复对比等原型能力。

本版重点是建立可公开管理、复现和迭代的源码基线，不代表需求已经全部完成。请先在测试目录使用；真实播放、异常恢复、跨平台和大库性能仍需验证。

AI 特色目前是辅助开发流程与后续可解释的检索/标签方向；没有内置视觉理解、自然语言检索或 LLM。

附件是源码包，不是 Windows 安装程序，不包含媒体、数据库、截图缓存、私人资料或凭证。

完整说明见 README、docs/REQUIREMENTS.md 与 docs/ROADMAP.md。
