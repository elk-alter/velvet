# Velvet 0.1.0-alpha.5

本版围绕运行可靠性、目录政策和只读硬盘整理预览交付。应用仍处于早期公开测试阶段，主要验证环境为Windows NTFS。

## 本版新增

- 统一任务摘要、持久逻辑ID、启动对账、等待/资源原因、来源限流冷却和脱敏诊断。
- 后台启动、单实例/端口冲突说明、安全停止重启及独立测试端口；保留用户自动化配置，超时不强杀。
- 人工合集/禁止归组规则、范围预览；排除前确认、即时恢复、后台与聚合一致；修复排除后被扫描误标缺失。
- 完整离线双库、配置及可选图片备份，归档校验、恢复回滚点；alpha.4合成升级和回滚演练。
- 多硬盘只读盘点、卷身份/离线快照、哈希比较与偏好，未知/问题筛选、整理建议修正，四种模板、路径与空间冲突检查、计划修订和本地导出。
- 无损引用传输和轻量版本轮询；跨页批选、视频集选择范围、管理未保存提示与键盘交互修复。

## 验证及边界

后端完整回归、合成浏览器流程及源码包解压回归记录见[验收文档](ALPHA5-VALIDATION.md)。所有故障实验使用独立临时数据。源码附件不含Python、FFmpeg、依赖环境、原视频、数据库、私人图片或凭据。

五万文件首屏实测约17秒，尚未完成服务端分页/聚合改造，见[性能报告](ALPHA5-PERFORMANCE.md)。NTFS为实际验证环境，exFAT、FAT32物理盘、NAS/ARM及跨系统恢复未认证。来源站点可能改变，测试不代表全部站点始终可用。

整理计划不可执行。ORG-21–27复制试点因提交/恢复故障门槛不足延期；ORG-28–31移动、重命名和源处置仍是后续范围。

## 使用和升级

见[操作指南](ALPHA5-OPERATIONS.md)。升级前停机并保存完整数据快照；旧版本回滚使用旧程序和升级前资料。网页主库备份与完整双库备份的范围不同。配置备份可能包含凭据，请保密。

发布附件为已提交源码归档及SHA256SUMS.txt；不包含安装包或预构建容器镜像。发布源码与升级本机运行服务分别核验。
