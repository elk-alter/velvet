# alpha.5 需求与验收清单

基线：已发布alpha.4。整理日期：2026-11-04。状态：待开发/待验收，不代表已实现。依据 [体验审计](UX-AUDIT.md) U01–U09；本文件为alpha.5范围基线，替代旧路线图中“alpha.5标签治理”的版本分配。不承诺日期。

目标：运行可靠、等待原因可理解、目录排除一致、重启和恢复有证据。不是扩充入口的一版。

## 1. 统一任务记录与对账（U01）

|ID|必交付需求|验收|
|---|---|---|
|A5-01|扫描、刮削、资料同步、图片、OCR、重复检查具有统一任务摘要|同一入口显示类型、对象范围、状态、更新时间与结果；不隐藏已有来源任务|
|A5-02|统一状态语义与持久任务标识|排队/等待/运行/成功/部分失败/失败/取消/中断可区分；逐项结果不只存在内存|
|A5-03|提交幂等及去重|同一对象同一任务并发提交不重复；手动强制刷新与自动缓存策略明确|
|A5-04|启动对账与中断恢复|异常退出后不永久停在运行中；本地可安全重做，远程提交未确认转人工核对，不盲目重复提交|
|A5-05|取消与重试范围明确|停止领取、取消当前、取消全部分别说明；只结束本程序的子进程；有限重试不覆盖人工决策|

实现可保留不同执行器和存储；统一的是标识、状态、摘要与对账契约，不要求一次重写所有采集器。

## 2. 可靠启停（U02）

|ID|必交付需求|验收|
|---|---|---|
|A5-06|单实例与端口冲突说明|已有服务时可打开；非本服务占端口时报告冲突，不强杀不相关进程|
|A5-07|可靠后台启动及健康核验|控制界面关闭不意外结束服务；启动失败可见原因和日志位置；成功以HTTP健康检查确认|
|A5-08|安全停止/重启|保存开关→停止领取→等待/取消→确认退出→启动→核验→恢复开关；超时不静默强杀|
|A5-09|配置化运行地址与测试隔离|支持显式端口，Host校验与页面请求保持一致；测试实例不争用生产端口|

本版不强制交付安装包、托盘、自动更新服务或Windows系统服务注册。

## 3. 等待、资源与诊断（U04，支撑U01/U02）

|ID|必交付需求|验收|
|---|---|---|
|A5-10|可解释的等待原因|区分扫描占用、站点冷却、依赖缺失、目录离线、用户暂停；显示当前阶段和排队数量|
|A5-11|进度可信|已完成/总量/失败/跳过分开；总量未知不伪造百分比，不凭空提供ETA|
|A5-12|资源争用和人工任务优先|自动OCR/图片不无限堆积；手动任务优先级与并发限制明确，等待可定位|
|A5-13|脱敏诊断摘要|包含版本、工具可用性、任务ID和错误类别；默认不含媒体名称、路径、Token、OCR文字与偏好|

## 4. 目录集合规则可控（U05）

|ID|必交付需求|验收|
|---|---|---|
|A5-14|人工指定/取消合集根目录|不依赖目录名必须包含“合集”；设置可持久化、恢复及撤销|
|A5-15|归组影响预览和规则优先级|显示范围/成员数/嵌套归属；明确人工设置、禁止归组和自动推断的优先级|
|A5-16|展示分组不修改媒体关系|影片/版本/分段、播放进度、收藏及字段锁不被归组操作改写；跨目录版本有固定样本|

本版提供规则控制及基本入口；独立合集页面、完整封面编辑、分集拖拽重排归alpha.6及后续。

## 5. 排除闭环与一致性（U06/U07）

|ID|必交付需求|验收|
|---|---|---|
|A5-17|排除前预览|明确精确目录、子目录范围、受影响文件/影片数量及原文件保留；快捷操作有可读确认|
|A5-18|可撤销及恢复反馈|取消排除即时恢复已有索引可见性；新增文件需重扫时明确提示；重复操作幂等|
|A5-19|扫描与索引一致|跳过排除目录，不把排除误当缺失/离线，不修改原视频；支持多层和重叠规则|
|A5-20|所有后台任务遵守排除|扫描/自动刮削/图片/OCR/重复检查统一检查；已排队项目跳过，正在执行项在安全边界停止或丢弃结果|
|A5-21|聚合及展示一致|片库、演员、分类、搜索、计数、合集、待处理和默认版本统一；一版本被排除不隐藏同片其它有效版本|
|A5-22|路径规范化与离线恢复|Windows大小写/分隔符、目录边界、离线规则、恢复备份均有样本；不可把同前缀相邻目录一起排除|

精确目录与通配符暂可保留两类存储，但匹配与生效解释必须一致；完整规则编辑器可后续迭代。

## 6. 数据安全与恢复演练（U08）

|ID|必交付需求|验收|
|---|---|---|
|A5-23|明确备份范围并提供停止状态的完整备份路径|主库、独立来源库、配置、规则与可选缓存/证据逐项列明；凭据保管有提示|
|A5-24|备份/恢复互斥和失败保护|运行中写任务不能与恢复竞争；校验失败不破坏现库；恢复前回滚点与失败处理可复现|
|A5-25|旧库、旧备份迁移及恢复任务状态|重复迁移不丢字段；人工锁/偏好/关系/排除/合集配置/标记一致；不重放已经完成的远程请求|
|A5-26|升级与回滚演练|合成alpha.4资料→备份→alpha.5迁移→验证→回滚；核对源文件哈希及数据快照|

完整的跨系统/跨NAS灾难恢复认证不在本版承诺内。缓存可选不代表主资料可以遗漏。

## 7. 性能基线（U03：本版限基线与止损）

|ID|本版需求|验收|
|---|---|---|
|A5-27|1万/5万文件合成片库测量|记录环境、接口响应体、查询/首屏耗时、峰值内存及轮询开销，可重复运行|
|A5-28|针对测量结果做有证据的止损|减少明确冗余查询/隐藏页面轮询，不破坏筛选、计数与返回；前后测量对比|

完整服务端分页/过滤/聚合与增量API是后续专项，不将全部U03强塞进alpha.5；若基线证明当前规模不可用，再显式调整范围。

## 8. 测试与交付门槛（U09）

|ID|必交付需求|验收|
|---|---|---|
|A5-29|确定性后端回归|覆盖幂等、超时、限流、取消、中断、迁移、人工保护、排除与恢复|
|A5-30|合成资料浏览器回归|筛选、分页/跳转、历史/返回、详情与合集、批量范围、排除/恢复、隐私遮图及未保存状态|
|A5-31|端到端运行场景|首次启动、端口冲突、重启、任务恢复、离线目录和恢复失败；记录桌面/窄屏/键盘结果|
|A5-32|可复核发布证据|更新功能/缺口与CHANGELOG；源码包解压测试、校验和；区分已合并、已发布、已部署|

不以固定测试数量为验收；需要相关行为与失败场景的证据。自动浏览器脚本未覆盖的部分须保留人工记录，不冒充全自动验收。

## 依赖及实施批次

1. 定义任务状态/目录政策契约及迁移（01–05、19–22），建立失败样本。
2. 启停与等待诊断（06–13），再接统一任务摘要。
3. 人工合集规则、排除预览/撤销（14–18），贯穿聚合与后台执行。
4. 备份迁移演练（23–26）、性能基线（27–28）。
5. 29–32贯穿各批次，发布前汇总证据；每个需求维护待开发/实现中/待验收/通过/延期及理由。

## 明确不纳入alpha.5

标签可视化治理、动态片单、人物身份合并、独立合集页面、整体顶部导航重设计、通用视觉语义AI、外部最高画质发现、转码、字幕/音轨完整管理、安装包/自动更新及真实NAS全平台认证。已有功能的回归缺陷仍可修复，不因此扩大新功能范围。
