# alpha.11 界面统一

以已发布并本机运行的 alpha.10 为基线。目标是让片库、详情、演员与分类、管理与设置看起来属于同一个产品。alpha.10 已交付的业务能力和入口作为交互回归基线。

## 这版先解决什么

- 页面标题、标签页、工具条和操作栏目前分别由基础页、浏览样式与管理样式定义。先统一字号层级、页面留白、控件高度、导航选中态和主次操作。
- 卡片、详情、表格承担不同的信息密度。统一封面规格、文字层级、徽标和空状态，常用动作就近显示，低频动作收进明确的菜单或折叠区。
- 延续本地视频库的内容优先方向。使用克制的强调色、语义化状态色和稳定的布局。浅色、深色与隐私遮盖从同一套样式实现。

## 实施顺序

1. 用合成数据截图核对现状，确定信息层级和视觉基础。先完成片库、详情、管理各一页，验证它们在同一窗口尺寸下的观感与操作。
2. 扩展到演员、分类、合集、刮削、硬盘、媒体库、设置和常用弹窗。优先复用现有页面骨架与组件，边改边验证返回位置、键盘顺序、批选范围及隐私。
3. 比较改前改后截图和交互记录，完成性能回归、升级及发布验收。实现和测试证据记入交付台账。

## 性能基线

沿用同机五万条合成库和 [alpha.10 交付测量](DELIVERY-STATUS.md#alpha10)。保留索引重启首屏中位数目标 ≤1 秒，详情可操作 p95 ≤200 毫秒，翻页 p95 ≤300 毫秒。首次建索引单独记录，等待超过 1 秒时确保进度已可见并反映实际阶段。当前复测中位数为 3.61 秒，3.5 秒恢复目标安排在 alpha.12。遇到异常保留实测与复现条件。

alpha.12 接手跨页面流程改动与显示偏好。大规模前端重写、播放内核变化、NAS 新能力和物理整理策略调整列在后续路线图。
