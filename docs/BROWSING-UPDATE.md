# 浏览界面与人物分类

本轮参考 Amane 的演员、分类与片库浏览组织方式，继续沿用 Velvet 的影片/版本/分段模型和本地评分收藏。不是所有 Amane 交互与分类治理能力都已移植。

## 一个刮削主入口

侧栏仅保留“刮削中心”，其内部包含任务、来源、网络检测和连接设置。选中影片后的批量刮削和详情中的重新刮削仍作为上下文操作，提交后也进入同一个中心。原设置窗口不再重复展示刮削连接表单。

## 演员

演员页改为头像卡片，保留姓名搜索、收藏筛选、作品数/评分排序、评分与收藏，点击进入该演员的本地影片。详情显示已获取的头像、别名、简介和基础资料。

本页演员来自当前片库，不导入 Amane 中全部人物。打开页面时按需补全当前页最多 36 位演员头像；优先向配置的 Amane 按姓名精确匹配，多个同名结果不自动选取。无可用头像时读取本机 Amane 的只读 GFriends 索引，或下载公开 Filetree 索引，再按精确姓名查找图片。没有匹配项时保留占位图，不用相似姓名猜测身份。

头像写入 `data/actors/`，按姓名的 SHA-256 命名。资料存在主库 `actor_profiles`；收藏与评分仍在原偏好表中，不被同步覆盖。失败结果缓存一天，可点击“重新获取本页头像”重试；已有有效图片不被失败响应覆盖。GFriends 只能补图，不保证能补齐简介等资料。Amane 未运行时，该部分人物资料同步不可用。

2026-11-02 已对两位片库演员验证头像下载成功。新增测试覆盖精确/同名匹配、坏图片不覆盖缓存。不能据此承诺全部演员都有头像。

## 分类

新增独立分类页，分为题材、厂商、系列、导演、我的标签和媒体属性。可搜索、收藏分类，并进入对应影片继续使用现有组合筛选。数量按影片关系去重，同时显示本地文件数。离线文件不计入当前可浏览分类。

分类收藏写入主库 `category_preferences`。题材沿用既有标签别名配置；本轮尚未加入完整的可视化别名合并、分类删除、黑名单和冲突治理。系列和导演依赖已有元数据快照，不凭文件名编造。

## 视频展示

提供海报与横版布局切换；布局偏好保存在浏览器。缩略图依次回退到封面和本地截图，保留悬停截图预览。卡片简化边框、阴影和信息层次，标题最多两行；分辨率、VR、精品、有码/无码、分段及版本提示继续保留。批量选择操作只在选择后展示刮削按钮。

本轮的浏览器验证使用隔离的合成演员与影片，不将真实封面、头像、路径或私人片库写入公开仓库。运行缓存仍被 Git 忽略。原视频只读，不改名、不移动、不删除。
