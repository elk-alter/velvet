# Velvet 0.1.0-alpha.2

第二个公开测试版：独立内置刮削、剧照画廊、人物与分类浏览，以及统一管理导航。

## 本版变化

- 10 个内置采集适配器，来源/字段择优、站点配置、缓存复用、自动任务及网络诊断；无需运行 Amane 即可使用内置流程。
- 24 项来源目录中，其它 14 项仍依赖可选的外部 Amane，不表示 24 项全部已原生实现。
- 单库自动化与文件筛选、演员头像及偏好、分类收藏、持久剧照下载和详情放大画廊。
- 管理收敛为媒体库/刮削中心/设置；支持管理地址恢复、返回和请求取消。
- 调整卡片画质/时长及选择框，移除悬停“查看”和轮播；详情按需展开播放与编辑。
- 功能清单、待办验收、分阶段计划、代码边界和可重复源码打包流程完成整理。

## 安装与升级

源码包需要 Python 3.10+；内置刮削先安装 `requirements.txt`，媒体参数与截图需 FFmpeg/ffprobe。Node.js 仅用于开发发布校验。包内没有媒体、运行数据库、头像缓存、Cookie 或访问 Token。

从 alpha.1 升级前，暂停自动任务并等待扫描、同步与图片任务结束，停止服务，复制完整 data 目录并保存旧程序。解压新源码到新目录，配置 VELVET_DATA 指向原数据，再启动。回滚时使用旧程序及升级前的数据快照。详细说明见 docs/DEPLOYMENT.md。

## 验证范围

43 项后端测试覆盖临时片库、任务、来源解析/缓存、关系、备份、人物及剧照，包含本版静态资源交付回归；前端外部和内联脚本完成语法检查。已在隔离演示片库验证管理导航/刷新/前进后退、横版/海报卡片及选择交互。源码附件另做解压测试与 SHA-256 校验。

既有真实来源小样本验证不代表所有来源持续可用；真实媒体全编码/连续播放、长时间恢复、大库性能和 NAS/其它操作系统实机尚未完成。CI 示例未激活。本版不是安装程序，也未发布容器镜像。

## 后续与限制

下一阶段优先统一任务恢复、待匹配审阅、失败退避和备份一致性；随后做标签治理、动态片单和大库查询。尚无产品内 LLM、视觉 AI、语义检索、转码、感知重复或自动删除。
