# 需求审计：初始测试版

更新：2026-11-02。版本：0.1.0-alpha.1。

## 如何理解本表

此前“P0 已完成”的标记过于笼统：它说明原型入口和部分测试已经存在，不等于真实媒体、异常网络、跨平台、长时间运行都经过完整验收。本表重新以实际实现和验证缺口为准，不把按钮存在当成功能闭环。

- **原型可用**：核心路径存在，在本机或临时数据上验证过。
- **部分实现**：存在明确缺口，不应认为已完成。
- **待开发**：尚无对应实现。
- **非当前目标**：有意不做，或需用户另行决定。

阶段 A 优先可靠性与数据一致性；B 优先日常体验；C 为 AI 探索；D 为部署扩展。此表是范围说明，不是交付日期承诺。

## 退出 Alpha 的条件

1. 阶段 A 的关键一致性和可靠性问题有可复现测试及修复。
2. 用一套可公开再现的合成媒体验证不同版本、连续播放、字幕和恢复流程。
3. 对目标库规模建立查询、首屏、扫描与图片任务性能基线。
4. 在文档标明已验证平台、播放编码和部署方式，不以“代码可运行”代替验收。
5. 发布流程只包含源码、演示素材和通用文档，排除私人媒体、偏好与凭证。

本表中的未完成项不会因首个公开测试版发布而自动改为完成。
