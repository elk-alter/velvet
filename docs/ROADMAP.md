# Roadmap

本项目先让原型可靠，再扩展体验。这里列的是方向，不是日期承诺。

## A · 可靠的本地资料库

- 补齐编号识别与关系模型的合成媒体样本集。
- 任务幂等、重启对账、取消与逐项错误。
- 真正的分段播放/续播端到端测试与浏览状态回归。
- 恢复演练、迁移、一致性和日志脱敏。
- 模块化、稳定 API、服务端分页与大库性能。

## B · 更顺手的日常使用

- 动态片单、手工收藏集和首页分区。
- 人物别名、头像、厂商/系列浏览。
- 标签治理、封面选择、截图重采样。
- 字幕/音轨、播放器配置、观看历史。
- 触摸、键盘和无障碍体验。

## C · 可解释的 AI 探索

- 自然语言生成可检查的筛选条件。
- 可选模型提供标签建议，用户决定是否采用。
- 本地优先的视觉语义索引与感知重复候选。

当前没有上述产品内 AI 功能。不会把关键词规则包装成视觉 AI，也不会默认上传媒体。

## D · 分发与跨设备

- Windows 安装包、托盘和可靠升级。
- macOS/Linux 原生交互验证。
- NAS/Docker 真机、路径迁移和权限。
- 按需转码与硬件加速。

完整状态见 [需求审计](REQUIREMENTS.md)。
