## alpha.6 基础交付

独立硬盘工作区、多盘快照与查询、固定计划、安全复制和同盘移动、校验绑定、同挂载路径下恢复及撤销。主片库使用服务端分页并按需读取详情。首发以 Windows NTFS 合成资料及实际文件操作验收。见 [首发范围](ALPHA6-REQUIREMENTS.md) 与 [版本说明](RELEASE-0.1.0-alpha.6.md)。

## alpha.7 整理恢复与资料治理

优先补齐变更盘符或挂载后的任务恢复，覆盖移动暂存、已提交文件、绑定、撤销和日志对账。补真实拔盘、exFAT 及多分区设备验证，扩展故障与竞争矩阵。继续完善筛选、历史返回和管理表单。

U20–U30：自动检测反馈和稳定证据、问题级决策、标签规则/别名、人物身份治理及隐私增强。动态片单和选图视范围评估，不视为已经承诺完成。

## 后续专项

字幕音轨、观看历史、片单首页、NAS/跨平台验证、安装分发、缓存治理、模块拆分和按需转码。自然语言/视觉语义AI须先定义数据范围、模型依赖和质量评估。

上述是交付顺序而非日期承诺。日常浏览/扫描及开发测试保持原媒体只读；alpha.6执行仅限用户明确确认的具体计划，不以入口存在代替验收。
