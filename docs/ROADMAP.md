## alpha.6 基础交付

独立硬盘工作区、多盘快照与查询、固定计划、安全复制和同盘移动、校验绑定、同挂载路径下恢复及撤销。主片库使用服务端分页并按需读取详情。首发以 Windows NTFS 合成资料及实际文件操作验收。见 [首发范围](ALPHA6-REQUIREMENTS.md) 与 [版本说明](RELEASE-0.1.0-alpha.6.md)。

## alpha.7 性能、功能与界面完善

[完整需求与验收 A7-01–16](ALPHA7-REQUIREMENTS.md)。以 alpha.6 为基线，先量化大库冷首屏、新筛选、图片与后台并发，再改善列表、卡片、详情和管理导航。保留索引的冷启动目标为 1 秒，首次建索引争取同一目标，等待达到 1 秒时显示真实进度。补齐换盘符后的安全续跑、批量刮削失败处理和问题级质量审阅。

真实拔盘、exFAT 与多分区列为设备可用后验证；先在 NTFS 合成媒体上验收任务恢复。标签和人物治理、合集选图等按 P1 排期。
