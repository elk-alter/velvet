# 迭代路线图

当前版本：alpha.5。最新结构审计见 [U01–U40](UX-AUDIT.md)，已实现功能见 [功能清单](FEATURES.md)。版本顺序以本文件为准，历史版本说明保留当时范围，不是当前承诺。

## alpha.5：可靠性与目录政策闭环

**[完整需求及验收：A5-01–A5-32](ALPHA5-REQUIREMENTS.md)**。

统一任务/重启对账、安全启停、等待诊断、人工合集规则、目录排除一致性、完整数据备份路径和迁移演练、性能基线、端到端回归。

新增 [E-ORG 原始媒体整理Epic](EPIC-RAW-MEDIA-ORGANIZATION.md)：alpha.5先交付多盘盘点和只读整理预览；安全复制条件试点，实际移动后续评审。

U03本版先做基线和明确止损，完整服务端查询改造后续专项推进；不承诺一次完成所有大库优化。交付实现与证据见[开发进度](ALPHA5-PROGRESS.md)和[验收记录](ALPHA5-VALIDATION.md)，复制条件试点延期。

## alpha.6：硬盘文件统一管理（必达）与大库查询

用户于2026-11-04明确要求硬盘统一管理为本版必达。权威范围见 **[alpha.6 Feature/Story及验收：A6-01–30](ALPHA6-REQUIREMENTS.md)**。

独立硬盘管理工作区、多盘搜索/重连、方案审阅与批准、安全复制、同盘改名/移动、跨盘整理、任务恢复/撤销及片库保真绑定构成完整闭环。ORG-21–27从条件试点升级为本版必达，ORG-28–30及ORG-31受控源归档一并纳入；不能仅交预览后发布。当前规划不授权实际整理用户硬盘。

服务端分页/筛选/聚合、按需详情为P0基础，解决alpha.5五万文件首屏约17秒的问题；性能目标和测量方法见新需求。浏览结构同时交付独立合集页、明确选择范围、工作区入口和返回一致性；封面自选及其他增强可按P1延期。

优先顺序：身份/位置/执行日志与互斥契约→大库查询和工作区→执行/校验/绑定→恢复/撤销→故障/实盘/浏览器验收→发布。全部P0未过不能降级为预览版放行。

## alpha.7：识别审阅与资料治理

U20–U30：自动检测反馈和稳定证据、问题级决策、标签规则/别名、人物身份治理及隐私增强。动态片单和选图视范围评估，不视为已经承诺完成。

## 后续专项

字幕音轨、观看历史、片单首页、NAS/跨平台验证、安装分发、缓存治理、模块拆分和按需转码。自然语言/视觉语义AI须先定义数据范围、模型依赖和质量评估。

上述是交付顺序而非日期承诺。日常浏览/扫描及开发测试保持原媒体只读；alpha.6执行仅限用户明确确认的具体计划，不以入口存在代替验收。
