# Velvet 0.1.0-alpha.6

Windows NTFS 本地影库的硬盘整理预发布版。可在同一工作区登记多块盘、查看离线快照、筛选文件并审阅整理计划。

- 支持原位保留、同盘改名与移动，以及跨卷复制。复制校验完整 SHA-256 后才提交目标并绑定片库，默认保留源文件。明确归属的字幕、NFO 和图片可一起整理。
- 任务分开记录复制、校验、提交和绑定。支持暂停、取消、同一挂载路径下的重启恢复、未提交文件组的显式跳过，以及独立确认的撤销与源归档。
- 片库和硬盘文件使用服务端分页。详情按需加载版本、分段和剧照。支持独立合集页、跨页选择、隐私遮图和编辑保护。
- 硬盘页提供目录重连和替换位置登记。旧快照与人工建议保留。

首发验收使用 Windows NTFS 合成媒体，覆盖实际同盘和跨卷文件操作、检查点恢复、绑定、撤销、升级与受控回滚。浏览器验收覆盖整理范围、任务操作、重连和窄屏。五万条合成记录的两轮冷首屏约 4.55–4.59 秒。详见 [开发验收记录](ALPHA6-PROGRESS.md)、[性能报告](ALPHA6-PERFORMANCE.md) 和 [升级演练](ALPHA6-UPGRADE-VALIDATION.md)。

开始前先备份整个数据目录，使用少量文件试跑。继续已有任务时，先恢复批准时的挂载路径，再从原任务核对和继续。移动暂存交由原任务处理。数据库恢复只恢复资料，物理文件按任务日志另行对账。详见 [整理操作指南](ALPHA6-OPERATIONS.md) 和 [部署与升级](DEPLOYMENT.md)。

下一迭代补齐变更挂载后的任务续跑、真实拔盘和 exFAT 验收、扩展故障矩阵及浏览细节。首发范围见 [需求和验收边界](ALPHA6-REQUIREMENTS.md)。

发行附件为源码 ZIP 和 SHA-256 校验文件。启动需要 Python 3.10+。Node.js 用于开发回归，FFmpeg 用于媒体探测及截图。
