# 使用与配置

## 运行

需要 Python 3.10+，运行 `python app.py`；在 macOS/Linux 上通常为 `python3 app.py`。Windows 可双击 `启动.bat`。默认地址为 http://127.0.0.1:8765 ，关闭服务进程即可退出。

FFmpeg 与 ffprobe 放进 PATH 或 `tools/`。缺少时仍能建立文件索引，但截图、媒体参数与相关筛选不完整。安装后重新启动并扫描。

## 添加资料

使用「导入目录」选择运行服务的电脑上的目录。会递归处理支持的扩展名，不移动源文件。原生选择器无法打开时使用备用路径输入。首次建议小目录试运行。

## 元数据与分类

同名 NFO 可提供标题、人物、厂商、日期和标签；也可配置通用 HTTPS JSON 接口，或连接独立的 Amane 服务。后者支持按编号的自动队列和资料/图片同步。元数据来源并不保证每个文件都能正确匹配，需检查未知项与缺字段条目。

Windows 默认可读取 Amane 自己的本地 Token 文件。跨机器应在设置中指定服务地址与 Token，远程连接要求 HTTPS。自动模式按编号去重、限制在途任务，来源需要核对的失败不会无限重试。

手工标签、来源题材、技术参数和规则标签用于组合筛选。规则是关键词与媒体属性规则，不是画面理解。可设置标签别名，保留原始来源值。

## 影片、版本与分段

同一影片可有不同编码、画质或剪辑版本，每个版本可含多段。详情页选择播放版本与分段，并可设默认版本。关系编辑不会改文件，可撤销上次关系变更。自动识别依赖目录、编号和文件名；不确定时手动检查。

续播和自动下一段限浏览器能够解码的文件。其他格式可尝试系统播放器；本版没有外部进度回传，也没有服务器转码。

## 重复对比

相同大小的候选会进行完整 SHA-256 校验，确认字节完全相同的副本。相同影片编号的不同文件只作为版本候选。选择优先保留会影响默认展示/播放，不删除其他文件。不同编码但同画面的识别尚未实现。

## 数据与备份

默认数据位于 `data/`。设置 `VELVET_DATA` 环境变量可改变位置。数据库、配置和规则可备份，恢复前校验并生成回滚点；执行恢复前暂停自动队列，并等待后台任务结束。

备份不打包源视频和可再生成的图片缓存；配置可能包含访问凭证。迁移目录不会自动迁移媒体路径。跨系统迁移和完整故障恢复仍需要进一步验证。
