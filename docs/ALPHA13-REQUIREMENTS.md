# alpha.13 常用操作与播放

| ID | 优先级 | 验收 |
|---|---|---|
| A13-01 | P0 | 详情、图片预览、筛选、选择目录及确认弹窗的关闭按钮固定在右上角。管理二级页在左上返回实际进入的页面，恢复仍有效的查询、页码、滚动和焦点。草稿拦截点击、Esc 和历史返回。 |
| A13-02 | P0 | 硬盘首页可在应用内浏览本机盘符和子目录，也可粘贴路径或调用 Windows 选择器。添加前核对已登记位置、设备身份变化与新位置。可仅添加或添加并盘点。重连及目标目录共用选择器，文件操作仍按原有计划确认。 |
| A13-03 | P0 | 筛选集中在独立弹窗。支持多个标签与组合条件，取消保留当前结果，确认后从第一页展示并更新历史状态。选择栏显示跨页范围，保留明确选择与原条件。 |
| A13-04 | P0 | 原详情中播放、续播及切换分段。离线、读取失败、浏览器不支持有各自提示。本地模式可回退系统播放器。同名相邻 VTT 与 SRT 按需加载，浏览器可枚举多个音轨时提供切换。 |
| A13-05 | P0 | 待处理按编号、网络或来源故障、站点限制、缺图筛选，提供对应操作。重试预览给出可提交、执行中和需人工处理的数量。只提交确认范围的最新可重试任务。 |
| A13-06 | P0 | 硬盘首页展示设备、在线状态、最近盘点和待恢复任务。任务仍可单独检查进度、确认恢复和撤销。 |

## 发布验收

- 同机 Windows、Edge 桌面和 390px，以合成目录、影片、字幕和作业测试。另验收解包启动、全量回归、升级回滚和本机部署。
- 五万条合成库首次建索引首屏中位数 ≤3.5 秒。等待达 1 秒前出现实际进度。保留索引冷首屏中位数 ≤1 秒，详情 p95 ≤200 毫秒，分页 p95 ≤300 毫秒。
- 原媒体保持只读。格式兼容受浏览器及系统解码器影响。物理拔盘、变更盘符、exFAT 和 NAS 独立记录。
