# Velvet 0.1.0-alpha.12

本次预发布改善四条日常使用流程。

- **找片**显示当前条件和命中作品数。可逐项移除条件，保存筛选后可直接复用。本页选择、跨页总选择和合集内命中范围分别显示。
- **连续浏览**可在详情里打开当前结果页的上一部或下一部。关闭详情回到起始卡片，未保存的编辑继续受保护。
- **待处理**按当前编号显示最近失败及处理建议，可直接打开编号编辑。补封面使用已保存的图片地址，保留已有缓存图片和资料。
- **硬盘整理**在计划审阅及执行确认展示原筛选范围，当前会话可回到原快照和文件选择。源盘、文件状态和目标冲突提供对应处理提示。

初次创建索引减少了重复的关系查找和媒体标记计算。索引较大时仍显示检查、建立索引和整理作品的实际阶段。本机服务可接住浏览器启动时并发发出的资源请求。

附件包括源码 ZIP 与 SHA-256 校验值。升级、回退与后续安排见 [部署说明](DEPLOYMENT.md) 和 [路线图](ROADMAP.md)。
