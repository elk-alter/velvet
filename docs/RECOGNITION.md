# 自动标记与人工修正

文件详情和卡片使用同一后端识别模块。有码／无码优先级依次是人工选择、文件名或直接父目录的明确标记、来源资料、受约束片商规则。国产和素人保留自动、始终显示、始终隐藏设置。

详情的识别依据显示生效原因和来源冲突。冲突不自动选择一个来源。来源快照作为原始资料保留，人工标记可以随时恢复为自动。

## 片商规则

|规则|适用条件|结果|反例|
|---|---|---|---|
|Tokyo-Hot|片商名称精确匹配 Tokyo-Hot/Tokyo Hot/Tokyohot/東京熱/东京热，并且编号匹配 n 加 4–5 位数字。或文件名/直接父目录具有带边界的品牌与该编号组合。|推定无码|仅 n1153、品牌提及但没有匹配编号、明确的有码版本标记均不能靠本规则改判。|

规则背景见 Tokyo-Hot 的公开作品系列资料。规则只描述对应发行资料的推定，用户仍可按本地文件实际版本修正。[作品系列资料](https://zh.wikipedia.org/wiki/%E6%9D%B1%E4%BA%AC%E7%86%B1%E4%BD%9C%E5%93%81%E5%88%97%E8%A1%A8)

## 国产和素人

优先读取来源的明确标签、产地和内容类型，名称中的明确标记也可参与判断。中文文件名作为国产推定依据；明确非大陆产地、日语假名和中文字幕标记阻止这条推定。素人使用明确标签，不依据演员照片或外貌判断。

判断为未标记表示缺少正向依据或用户选择隐藏。查询页的“无国产标记”“无素人标记”按这个含义筛选。

## 质量检查

现有本地 OCR、黑屏、静止和解码检查继续使用独立的质量审阅流程，详见 [自动问题识别](AUTOMATIC-MARKS.md)。画面语义识别另作实验规划。
