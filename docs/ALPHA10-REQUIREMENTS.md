# alpha.10 标签、人物与浏览

以 v0.1.0-alpha.9 为基线，承接 A7-08、A7-09、A7-15。默认保留来源资料和已有个人偏好。

| ID | 优先级 | 验收条件 |
|---|---|---|
| A10-01 | P0 | 可逐行编辑标签别名和关键词规则。预览列出影响文件数和样例；保存与撤销重新核对预览范围。来源快照与人工标签保持可追溯，筛选、分类和详情使用生效标签。 |
| A10-02 | P0 | 预览演员别名合并及同名拆分；选定拆分文件及目标评分、收藏，完成后可按主名称或别名查找作品。能撤销最近一次身份变更；目标偏好后续被编辑时提示冲突。 |
| A10-03 | P0 | 当前筛选可命名保存和恢复，空结果显示所用条件。演员库和分类有页码与跳转，合集可选择成员封面或恢复拼图。 |
| A10-04 | P0 | 隐私遮图可选同时遮盖片库与详情中常用的标题、路径，其他标签页同步当前设置。桌面及 390px 完成治理表单、刷新与详情回归。 |
| A10-05 | P0 | 执行全量、打包解压、alpha.9 基线升级与回滚。核对 GitHub 标签、附件以及 Windows 本机部署版本。 |

筛选预设保存在当前浏览器，每个浏览器最多 30 个。标签和演员的撤销各保留最近一次治理变更，并在持久化数据中保存。合集封面基于已有成员素材。隐私模式用于减少界面中的内容暴露。原始演员资料、来源标签和原媒体文件作为独立记录保留。

实现状态与验收见 [交付台账](DELIVERY-STATUS.md)。界面入口见 [版本说明](RELEASE-0.1.0-alpha.10.md)。
