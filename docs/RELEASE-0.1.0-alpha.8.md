# Velvet 0.1.0-alpha.8

日常使用稳定版，基线为 alpha.7。验收结果与边界见 [验收记录](ALPHA8-VALIDATION.md)。

## 使用变化

- 在影片详情中直接点击类别标签筛选，编辑后与片库分类保持一致，再刮削保留人工结果。
- 来源评分显示来源和已知量表，个人评分以 0–5 星独立编辑。
- 自动识别有码／无码、国产和素人，支持人工修正和恢复自动。详情可以查看依据与来源冲突。
- 国产／素人标记可以筛选。Tokyo-Hot 品牌和编号共同匹配时可推定无码。
- 移除媒体库后，其普通库外记录隐藏；索引保留，重新添加可恢复。整理任务主动纳管副本继续显示。
- 文件页显示目录状态及上次扫描。Windows 短路径对应的文件重扫复用原记录。
- 刮削任务增加来源访问限制筛选和下一步处理建议，常规设置显示版本、服务及任务状态。

## 升级

等待任务结束，安全停止 alpha.7，保存整个数据目录及旧程序。将新源码解压到独立目录，在数据副本上升级。核对健康版本、媒体库、类别、人工标记、评分、进度和任务。回滚使用旧程序和升级前数据快照，操作步骤见 [部署指南](DEPLOYMENT.md)。

派生索引模式升级到 11，首次查询可能重建索引并显示进度。手工资料和来源快照保持独立，标记筛选与卡片使用相同生效结果。

## 验证边界

主验收环境为 Windows NTFS 与合成媒体。来源站点的网络、账号和验证限制按独立实际检测记录。真实外接盘、exFAT、NAS 实机、通用画面语义识别及安装包列入后续迭代，详见 [路线图](ROADMAP.md)。
