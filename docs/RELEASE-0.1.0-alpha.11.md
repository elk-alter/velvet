# Velvet 0.1.0-alpha.11

本次预发布统一片库、详情和管理界面的设计，给封面与主要操作留出更多空间。

- 片库页头保留选片、随机、导入与隐私入口，布局、主题、预览和目录显示归入「显示选项」。标签仍支持展开和多选，手机可通过紧凑导航访问管理功能。
- 影片卡片统一封面边框、标题和技术信息位置。分辨率和时长在同一行，常用徽标保持可见。
- 详情固定标题和独立关闭按钮。概览后直接展示剧照，质量检查和资料编辑按需展开。
- 演员库、分类、合集和各管理区沿用统一的主题、标题层级、控件、分页及焦点样式。浅色与深色共用同一套结构。

附件包括源码 ZIP 和 SHA-256 校验值。升级与回滚见 [部署说明](DEPLOYMENT.md)，版本排期见 [路线图](ROADMAP.md)。
