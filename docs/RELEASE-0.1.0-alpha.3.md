# Velvet 0.1.0-alpha.3

文件质量与待处理的第一版：人工水印/损坏/更新标记、只读快速探测/抽样/完整解码、个人画质目标、本地更高分辨率候选和批量待更新清单。标记属于具体文件，支持接受、忽略、撤销和备注；文件变化后需重新审阅。

恢复可关闭的延迟悬停截图预览；4K 不再等同精品。检查队列持久化、可取消、重启重查，记录随主片库备份。

50项后端测试通过；合成视频通过实际 ffprobe/FFmpeg 三类检查，截断容器识别为探测异常，主库恢复标记且源视频 SHA-256 不变。浏览器演示数据验证目标筛选、批量接受、单片标记和刷新恢复。未对个人片库执行全量完整解码。

仍为 Alpha。水印需人工确认，不自动发现外部最高画质；抽样/解码通过不证明全片视觉质量。全部 P0 尚未完成，统一任务、匹配候选、完整灾难恢复继续迭代。源码需 Python 3.10+、requirements.txt；媒体检查需 FFmpeg/ffprobe。升级前停止任务、保存完整数据目录；回滚用旧程序与升级前快照。
